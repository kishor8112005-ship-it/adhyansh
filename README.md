# Adiyash Gym — Kandivali (website rebuild)

A single-branch, mobile-first rebuild concept for the Kandivali East gym.
Static site — no build step, no dependencies.

**Run it:** open `index.html`, or `python3 -m http.server 8080` in this folder.

- `index.html` — the full landing page
- `styles.css` — design system (tokens, type, layout, responsive states)
- `main.js` — nav, reveals, counters, live IST clock, footfall chart, filters, gallery, FAQ, trial form
- `assets/` — custom images, self-hosted fonts, favicon
- `concept.md` — the design rationale, creative ideas, and everything to confirm before publishing

Rates, phone number and review quotes are placeholders/indicative — see `concept.md`.
